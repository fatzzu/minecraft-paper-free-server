# Oracle Cloud Always Free

Oracle is the best free option if it is available in your region because it can
run a real Linux server and can stay online. The free Ampere A1 capacity is not
always available, so you may see an "out of host capacity" error. If that
happens, try another availability domain or wait and retry later.

## Steps in Oracle

1. Create or sign in to Oracle Cloud.
2. Accept Oracle's terms. Oracle may request a mobile phone and a credit card.
   Oracle's Free Tier docs say the card is not charged unless you upgrade.
3. Choose your home region carefully. Always Free compute must be created in
   the home region.
4. Create a Compute instance:
   - Image: Ubuntu
   - Shape: `VM.Standard.A1.Flex`
   - OCPU/RAM: 2 OCPU and 12 GB RAM if available
   - SSH: use an SSH key generated by Oracle or your own public key
5. In the instance network settings, open Minecraft:
   - Source CIDR: `0.0.0.0/0`
   - Protocol: TCP
   - Destination port: `25565`
6. Keep SSH port `22` restricted to your own IP if you know how.

## Install on the VM

Connect with SSH:

```bash
ssh ubuntu@PUBLIC_IP
```

Then:

```bash
sudo apt-get update
sudo apt-get install -y git
git clone https://github.com/fatzzu/minecraft-paper-free-server.git
cd minecraft-paper-free-server
sudo bash scripts/install-oracle-ubuntu.sh
sudo bash scripts/add-player.sh YourMinecraftName op
sudo bash scripts/accept-eula.sh
```

Replace `YourMinecraftName` with your real Minecraft Java username.

## Manage the server

```bash
sudo systemctl status minecraft-paper --no-pager
sudo systemctl restart minecraft-paper
sudo systemctl stop minecraft-paper
sudo journalctl -u minecraft-paper -f
```

## Backups

```bash
sudo bash scripts/backup.sh
```

For a safer but offline backup:

```bash
sudo STOP_SERVER_FOR_BACKUP=true bash scripts/backup.sh
```
